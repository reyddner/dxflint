# dxflint

Lint the paper-space sheets of a DXF file before anyone prints or reviews them.
`dxflint` reads every layout, puts model-space text through each viewport's scale and reports, in plain text:

| Level | Finding |
|---|---|
| ERROR | text overlapping other text (on paper, after viewport scaling) |
| ERROR | text clipped by a viewport edge |
| ERROR | viewport, image or text outside the drawing frame, or over the title block |
| ERROR | overlapping viewports; an image covering text |
| ERROR | script leftovers in text: `nan`, `NaN`, `None`, `Traceback`, `{`, `}` |
| ERROR | text smaller than 1.8 mm on paper (outside the title block) |
| WARNING | nearly empty sheet (less than 45 % of the usable area occupied) |
| WARNING | hatch patterns the ezdxf PDF backend does not draw (`AR-CONC`, `AR-SAND`) |

It was written for drawings generated by scripts (and by AI agents), where nobody looks at every sheet
before the PDF goes out. It only needs [ezdxf](https://ezdxf.mozman.at/) and [shapely](https://shapely.readthedocs.io/).

## Install

```bash
pip install git+https://github.com/reyddner/dxflint
# or, from a clone:
pip install -e ".[test]"
```

## Use

```bash
dxflint drawing.dxf
dxflint drawing.dxf --json findings.json
```

```
A-01: 4 error(s)
   ERROR  viewport 1 overlaps the title block  [x 30-790 mm, y 70-530 mm]
   ERROR  1 text(s) smaller than 1.8 mm on paper (smallest 1.00 mm: "note in 1 mm text")  [x 0-841 mm, y 0-594 mm]
   ERROR  suspicious text (vp1): "AREA nan m2"  [x 217-353 mm, y 244-259 mm]
   ERROR  overlapping texts: "KITCHEN" x "KITCHEN"  [x 544-626 mm, y 294-309 mm]
TOTAL: 4 error(s), 0 warning(s)
```

Exit code is `0` without errors and `1` with errors, so it can gate a build or a CI job.

### Options and defaults

All coordinates are paper millimetres, origin at the lower-left corner of the sheet.

| Option | Default |
|---|---|
| `--frame x0,y0,x1,y1` | 25 mm margin on the left (filing edge), 7 mm on the other sides (ISO 5457 / ABNT NBR 10068) |
| `--title-block auto` | the largest closed polyline in the lower-right corner on a layer matching `--title-block-layers`; on an A1 sheet (841 x 594) with none drawn, the box `696,7,831,79` (135 x 72 mm at the lower right) |
| `--title-block none` | no title block checks |
| `--title-block x0,y0,x1,y1` | an explicit box (alias: `--carimbo`) |
| `--title-block-layers REGEX` | `carimbo\|title\|legend\|stamp\|selo\|cartouche\|schriftfeld` (case-insensitive) |
| `--min-text MM` | `1.8` |
| `--min-fill SHARE` | `0.45` |

Text width is measured with the text style's font, the same metrics ezdxf uses to plot. Only `TEXT` entities are
measured; `MTEXT`, dimensions and block attributes are not checked yet.

### Try it

```bash
python examples/make_example.py      # writes examples/example.dxf and examples/example_broken.dxf
dxflint examples/example.dxf         # TOTAL: 0 error(s), 0 warning(s)
dxflint examples/example_broken.dxf  # 4 errors
```

The example sheets are synthetic, generated by the script.

## Claude Code hook

`dxflint-hook` checks every DXF file that a `Bash` or `PowerShell` command just wrote, whatever program wrote it,
and hands the findings back to the agent as text (no screenshots needed). It looks in the session folder and in
any folder named in the command, skips `.git`, `node_modules`, virtualenvs and archive/backup/obsolete folders,
caps the scan at 2 seconds, and never blocks or breaks the session.

Add to `~/.claude/settings.json` (merge with the hooks you already have):

```json
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash|PowerShell", "hooks": [{ "type": "command", "command": "dxflint-hook pre" }] }
    ],
    "PostToolUse": [
      { "matcher": "Bash|PowerShell", "hooks": [{ "type": "command", "command": "dxflint-hook post" }] }
    ]
  }
}
```

If `dxflint-hook` is not on the `PATH` Claude Code sees, use `python -m dxflint.hook pre` / `post` with the
Python where dxflint is installed. The hook keeps a small timestamp file per command in
`~/.claude/dxflint-hook-state` (set `DXFLINT_HOOK_STATE` to move it).

The agent then sees something like:

```
[dxflint] 1 DXF file(s) written by this command:
- SHEET_R01.dxf (/work/job): 1 error(s), 0 warning(s)
    ERROR  suspicious text (sheet): "nan"  [x 100-115 mm, y 29-35 mm]  - sheet Layout1
Fix the ERROR lines before rendering or reviewing images. Text-only check: not a full drawing review.
```

## Português (pt-BR)

`dxflint` confere as pranchas (layouts do espaço papel) de um arquivo DXF antes de imprimir ou entregar:
texto sobreposto ou cortado pelo viewport, viewport/imagem/texto fora da moldura ou sobre o carimbo, viewports
sobrepostos, sobra de script no texto (`nan`, `None`, `{}`), texto menor que 1,8 mm no papel, folha vazia
(menos de 45 % ocupada) e hachuras que o PDF do ezdxf não desenha.

```bash
pip install git+https://github.com/reyddner/dxflint
dxflint prancha.dxf                 # código de saída 0 = sem erro, 1 = com erro
dxflint prancha.dxf --carimbo 696,7,831,79 --json achados.json
```

Padrões: moldura com 25 mm à esquerda e 7 mm nos outros lados (NBR 10068); carimbo = maior retângulo no canto
inferior direito numa camada cujo nome contenha `carimbo`, `title`, `legend`, `selo`…; em folha A1 sem carimbo
desenhado, a caixa `696,7,831,79`. `--carimbo none` desliga a checagem do carimbo; `--min-text` e `--min-fill`
mudam os limites.

O **hook do Claude Code** (`dxflint-hook`) confere todo DXF gravado por um comando `Bash` ou `PowerShell`, de
qualquer programa, e devolve os achados como texto para o agente. Veja a seção "Claude Code hook" acima para o
trecho do `~/.claude/settings.json`.
